# Obsidian ノート整理ツール

Obsidian の保管庫（ノートのフォルダ）を調べて、整理のための「提案レポート」を作るツールです。
Windows 11 で、ファイルをダブルクリックするだけで使えます。

## このツールでできること

| 機能 | 内容 |
| --- | --- |
| 1. 孤立ノート | どこからもリンクされていないノートを一覧にします |
| 2. リンク候補 | ほかのノートの名前が本文に出てくるのに、リンクになっていない箇所を見つけます |
| 3. リンク切れ | 存在しないノートへのリンクを一覧にします（全角・半角などの違いだけなら修正案も出します） |
| 4. タグの表記ゆれ | `#作劇` と `#さくげき`、`#キャラクター` と `#ｷｬﾗｸﾀｰ` のような似たタグを見つけて、統一案を出します |
| 5. 目次ノート案 | タグやフォルダごとに、関連ノートをまとめた目次ノートの案を作ります |

## いちばん大事なこと（安全のしくみ）

- **「レポート作成.bat」では、ノートを一切書き換えません。** 提案レポートを作るだけです。
- ノートを書き換えるのは **「提案を適用.bat」を実行したときだけ** です。
  - レポートで **チェックを入れた提案だけ** が反映されます。
  - 書き換える前に、**保管庫全体のバックアップ（ZIPファイル）を自動で作ります**。
  - 実行前に「よろしいですか？」と確認が出ます。`y` を入力するまで何も変わりません。
  - レポートを作ったあとに自分で編集したノートは、安全のため自動でスキップします。
- レポートとバックアップは、保管庫の **外** に保存されます。

## 使い方

### ステップ0：Python をインストールする（はじめての時だけ）

このツールは「Python（パイソン）」というソフトで動きます。

1. <https://www.python.org/downloads/> を開きます。
2. 黄色い「Download Python 3.xx」ボタンを押して、インストーラーをダウンロードします。
3. ダウンロードしたファイルをダブルクリックします。
4. **最初の画面の下にある「Add python.exe to PATH」に必ずチェックを入れて**から、「Install Now」を押します。
5. 「Setup was successful」と出たら完了です。「Close」で閉じます。

### ステップ1：ツールを置く

このツールのフォルダを、好きな場所に置きます（例：`C:\ツール\obsidian-organizer`）。

> ⚠️ ツールのフォルダは、**Obsidian の保管庫の外** に置いてください。
> （保管庫の中に置くと、レポートやバックアップが保管庫の中にできてしまうため、エラーになります）

GitHub からダウンロードする場合は、緑色の「Code」ボタン →「Download ZIP」でダウンロードし、
ZIP ファイルを右クリック →「すべて展開」で取り出してください。

### ステップ2：初回セットアップ（はじめての時だけ）

**「初回セットアップ.bat」** をダブルクリックします。
必要なライブラリが自動でインストールされます（数分かかることがあります）。
「セットアップが完了しました！」と出たら、何かキーを押してウィンドウを閉じます。

> 「Windows によって PC が保護されました」という青い画面が出たときは、
> 「詳細情報」→「実行」を押してください。

### ステップ3：保管庫の場所を設定する

**「設定.ini」** を右クリック →「プログラムから開く」→「メモ帳」で開きます。
次の行を、あなたの保管庫の場所に書き換えて、上書き保存（Ctrl + S）します。

```ini
保管庫フォルダ = C:\Obsidian
```

保管庫が `C:\Obsidian` にある場合は、そのままで大丈夫です。

### ステップ4（おすすめ）：サンプルで試してみる

**「サンプルで試す.bat」** をダブルクリックすると、練習用の「サンプル保管庫」で
提案レポートを作ります。あなたの本物のノートには一切触れないので、どんなレポートが出るか気軽に確認できます。

### ステップ5：提案レポートを作る

**「レポート作成.bat」** をダブルクリックします。
終わると「レポート」フォルダが開き、`提案レポート_日付_時刻.md` というファイルができています。

> このときノートは一切書き換えていません。何度実行しても大丈夫です。

### ステップ6：レポートを読んで、適用する提案を選ぶ

レポートは Markdown ファイルなので、次のどちらかで読めます。

- **Obsidian で読む（おすすめ）**
  Obsidian の左下の保管庫アイコン →「フォルダを保管庫として開く」で、このツールの **「レポート」フォルダ** を開きます。
  チェックボックスをクリックするだけで、適用する／しないを切り替えられます（自動で保存されます）。
  ノート名をクリックすると、本物の保管庫でそのノートが開きます。
- **メモ帳で読む**
  `- [x]` がチェックあり（適用する）、`- [ ]` がチェックなし（適用しない）です。
  `x` を消したり入れたりして、上書き保存します。

最初からチェックが入っているのは、比較的安全な提案だけです。

| 提案 | 最初の状態 |
| --- | --- |
| リンク候補 | ☑ チェックあり（`設定.ini` で変更できます） |
| リンク切れの修正案 | ☑ チェックあり |
| タグ：表記の違い（全角半角・ひらがなカタカナなど） | ☑ チェックあり |
| タグ：読みが同じ・つづりが似ている（要確認） | ☐ チェックなし |
| 目次ノート案 | ☐ チェックなし |

**タグの統一先を変えたいとき**は、レポートの「統一先：」のあとにある `#作劇` のようなタグ名を書き換えて保存してください。

> ⚠️ 行の先頭の `L-0001` や `T-0001` のような番号は、適用するときの目印です。消さないでください。

### ステップ7：提案を適用する

1. Obsidian で本物の保管庫を開いている場合は、念のため Obsidian を閉じます。
2. **「提案を適用.bat」** をダブルクリックします。
3. 適用される提案の件数が表示されるので、確認して `y` を入力し、Enter キーを押します。
   （やめるときは `n` を入力します）
4. 自動でバックアップが作られ、そのあと提案が反映されます。
5. 結果は「レポート」フォルダの `適用結果_日付_時刻.md` に記録されます。

使われるのは **一番新しい** 提案レポートです。

## 元に戻したいとき

適用する前の保管庫は、**「バックアップ」フォルダ** に ZIP ファイルで保存されています
（`保管庫バックアップ_保管庫名_日付_時刻.zip`）。

1. Obsidian を閉じます。
2. 今の保管庫フォルダ（例：`C:\Obsidian`）の名前を、`C:\Obsidian_適用後` などに変えておきます。
3. バックアップの ZIP ファイルを右クリック →「すべて展開」を選びます。
4. 展開してできたフォルダの中にある保管庫フォルダ（例：`Obsidian`）を、元の場所（例：`C:\` の中）に移動します。
5. Obsidian を開いて、元に戻っていることを確認します。

> バックアップは自動では削除されません。ディスクの空きが少なくなったら、古いものから手で削除してください。

## 提案の内容について、もう少しくわしく

### 1. 孤立ノート
ほかのどのノートからもリンクされていないノートです。「リンクが1本もないノート」と
「ほかのノートへのリンクは持っているノート」に分けて表示します。一覧を出すだけで、自動では何も変えません。

### 2. リンク候補
例えば「伏線」というノートがあるのに、別のノートの本文に「伏線」と書かれていてリンクになっていない場合に提案します。

- 適用すると、そのノートの中で **最初に出てくる1か所だけ** を `[[伏線]]` に書き換えます。
- 「伏線」と「伏線回収」のように名前が重なるときは、長い名前を優先します。
- 次の場所は書き換えません：見出し、コードブロック、`インラインコード`、すでにリンクになっている部分、URL、タグ、フロントマター。
- 英語の名前は、単語の途中には一致しません（`plot` が `plotting` の中に見つかることはありません）。
- ノートのフロントマターに `aliases`（別名）があれば、別名でも探します。
- 短すぎる名前や、よくある言葉の名前で候補が多すぎる場合は、`設定.ini` の `最小文字数` や `除外する名前` で調整できます。

### 3. リンク切れ
存在しないノートや添付ファイルへのリンクの一覧です。
`[[ミッド・ポイント]]` と `ミッドポイント.md` のように、全角／半角・ひらがな／カタカナ・記号の違いだけで
正しいノートが1つに決まるものは、修正案（チェック付き）を出します。それ以外は、似た名前のノートを参考として表示します。

### 4. タグの表記ゆれ
2つの段階に分けて提案します。

- **表記の違い**：全角／半角（`#ｷｬﾗｸﾀｰ` と `#キャラクター`）、大文字／小文字、ひらがな／カタカナ（`#ぷろっと` と `#プロット`）、記号（`-` `_` `・`）だけが違うもの。
- **読みが同じ・つづりが似ている（要確認）**：漢字とかなで読みが同じもの（`#作劇` と `#さくげき`）、のばす音の有無（`#キャラクター` と `#キャラクタ`）、つづりがよく似ているもの。
  読みが同じでも意味が違う言葉（例：「構成」と「校正」）がまざることがあるので、最初はチェックを外しています。

統一先は「たくさん使われているタグ」を基本に、同じ数なら漢字 → カタカナの順で選びます。
適用すると、本文の `#タグ` とフロントマターの `tags` の両方を書き換えます。

### 5. 目次ノート案
`設定.ini` の `最小ノート数`（最初は3）以上のノートがあるタグやフォルダについて、目次ノートの案を出します。
適用すると、保管庫の「目次」フォルダに新しいノートを作ります。同じ名前のノートがすでにあるときは作りません。

## 設定.ini でできること

| 項目 | 説明 | 最初の値 |
| --- | --- | --- |
| 保管庫フォルダ | Obsidian の保管庫の場所 | `C:\Obsidian` |
| レポートフォルダ | レポートの保存先（保管庫の外） | `レポート` |
| バックアップフォルダ | バックアップの保存先（保管庫の外） | `バックアップ` |
| 除外フォルダ | 調べないフォルダ | `.obsidian, .trash, テンプレート` |
| 最小文字数 | これより短いノート名はリンク候補にしない | `2` |
| 除外する名前 | リンク候補にしないノート名 | なし |
| 初期状態でチェック（リンク候補） | リンク候補に最初からチェックを入れるか | `はい` |
| 最小ノート数 | 目次ノート案を作る最小のノート数 | `3` |
| 作成先フォルダ | 目次ノートを作るフォルダ | `目次` |
| 初期状態でチェック（目次） | 目次ノート案に最初からチェックを入れるか | `いいえ` |
| Obsidianで開くリンクを付ける | レポートのノート名をクリックで開けるようにするか | `はい` |
| 完了後にフォルダを開く | レポート作成後にフォルダを開くか | `はい` |

「レポート」「バックアップ」のように場所だけを書くと、このツールのフォルダの中に作られます。
`D:\バックアップ\Obsidian` のように、ドライブから書くこともできます。

## こまったときは

| 症状 | 対処 |
| --- | --- |
| 「Python が見つかりませんでした」 | ステップ0 をやり直してください。「Add python.exe to PATH」のチェックを忘れずに。インストール後はパソコンを再起動すると確実です。 |
| 「まだセットアップが済んでいないようです」 | 「初回セットアップ.bat」を実行してください。 |
| 「保管庫フォルダが見つかりません」 | 「設定.ini」の `保管庫フォルダ` を確認してください。エクスプローラーで保管庫フォルダを開き、上のアドレス欄をクリックすると場所をコピーできます。 |
| 「レポートフォルダが保管庫の中になっています」 | ツールのフォルダを保管庫の外に移動するか、「設定.ini」でレポートフォルダの場所を変えてください。 |
| 「レポート作成後に変更されています」でスキップされた | レポートを作ったあとにノートを編集したためです。もう一度「レポート作成.bat」から始めてください。 |
| 「このレポートは別の保管庫について作られたものです」 | 「サンプルで試す.bat」のレポートが一番新しくなっています。「レポート作成.bat」をもう一度実行してください。 |
| セットアップがうまくいかない | ツールのフォルダの中の `.venv` フォルダを削除してから、もう一度「初回セットアップ.bat」を実行してください。 |
| 「予期しないエラーが起きました」 | 表示された内容をコピーして、作者に伝えてください。 |

## ファイルの一覧

```
obsidian-organizer\
├─ 初回セットアップ.bat   … 最初に1回だけ実行（ライブラリのインストール）
├─ レポート作成.bat       … 提案レポートを作る（ノートは変更しない）
├─ 提案を適用.bat         … バックアップを取ってから、提案を適用する
├─ サンプルで試す.bat     … 練習用のサンプル保管庫でレポートを作る
├─ 設定.ini               … 設定ファイル
├─ README.md              … この説明書
├─ サンプル保管庫\        … 練習・テスト用のノート
├─ organizer\             … プログラム本体（Python）
├─ tests\                 … 動作確認用のテスト
├─ requirements.txt       … 使うライブラリの一覧
├─ レポート\              … （実行すると作られます）提案レポートと適用結果
└─ バックアップ\          … （適用すると作られます）保管庫のバックアップ
```

## 開発者向けメモ

- 動作確認：`.venv\Scripts\python.exe -m unittest discover -s tests -t .`
- コマンドで直接使う場合：
  - `python -m organizer report` … レポート作成
  - `python -m organizer apply` … 適用（`--report ファイル` で使うレポートを指定）
  - `--vault フォルダ` で、設定ファイルより優先して保管庫を指定できます
- 必要なもの：Python 3.9 以上、PyYAML、pykakasi（漢字の読みの比較に使用）
- `.bat` ファイルは、日本語版 Windows のコマンドプロンプトで文字化けしないよう、Shift-JIS（CP932）・改行 CRLF で保存しています。
